# Research Validation

Sprint 1A backtests are not validation evidence. They are accounting and causality foundation simulations.

Every Sprint 1A run is permanently labelled:

- `FOUNDATION_SIMULATION_ONLY`
- `NOT_VALIDATED`
- `NOT_PAPER_TRADING_ELIGIBLE`
- `NOT_LIVE_TRADING_ELIGIBLE`
- `ZERO_COST_MODEL`
- `IMMEDIATE_SETTLEMENT_SIMULATION`
- `SINGLE_INSTRUMENT_ONLY`

No Sprint 1A run can be promoted to validated, paper-trading eligible, or live-trading eligible status.
