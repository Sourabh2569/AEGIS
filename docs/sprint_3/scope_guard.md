# Sprint 3 Scope Guard

Sprint 3 is paper trading only.

Forbidden:

- Broker APIs.
- Broker credentials.
- Real capital.
- Live order placement.
- Real-time execution.
- Live portfolio reconciliation.
- Broker holdings or funds.
- Live mode UI.
- Broker environment variables.

Mandatory labels:

```text
PAPER_TRADING_ONLY
NO_REAL_CAPITAL_DEPLOYED
NOT_LIVE_APPROVED
NOT_BROKER_CONNECTED
PAPER_RESULTS_DO_NOT_GUARANTEE_LIVE_PERFORMANCE
```
