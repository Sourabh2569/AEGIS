# Simulation Assumptions

Every Sprint 1A run is permanently labelled:

- `FOUNDATION_SIMULATION_ONLY`
- `NOT_VALIDATED`
- `NOT_PAPER_TRADING_ELIGIBLE`
- `NOT_LIVE_TRADING_ELIGIBLE`
- `ZERO_COST_MODEL`
- `IMMEDIATE_SETTLEMENT_SIMULATION`
- `SINGLE_INSTRUMENT_ONLY`

Execution occurs at the validated next eligible session open. Costs, taxes, brokerage, slippage, settlement delay, dividends, liquidity, and corporate actions are not modelled.
