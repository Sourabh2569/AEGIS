# Responsive Behavior

## Desktop

- Sidebar uses 272px width.
- Main content uses multi-column KPI, chart, and analytics grids.

## Laptop and Tablet

- Two-column analytical grids collapse to one column under 1180px.
- Sidebar becomes non-sticky and full-width.

## Mobile

- KPI grid becomes one column.
- Top controls and operating rail stack vertically.
- Tables remain horizontally scrollable.
- Page padding is reduced to preserve readable content width.
