# Accessibility Requirements

## Implemented

- Semantic buttons for navigation and actions.
- `aria-label` on operating status and icon-only controls.
- Statuses include text, not colour alone.
- Contrast uses the AEGIS token palette.
- Focus-visible states are present on navigation and controls.
- Reduced-motion preference disables transitions.
- Tables retain semantic `table`, `thead`, `tbody`, `th`, and `td`.
