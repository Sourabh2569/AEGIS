# Brand and Colour System

## Brand Source

The user provided the AEGIS logo lockup on June 27, 2026. It defines the app's primary colour system and supersedes the earlier fallback green palette.

The exact logo image is installed at:

```text
apps/web/public/brand/aegis-logo.png
```

## Token Source

Primary brand colours extracted from the provided logo board:

- `#B58AF7` soft violet
- `#8A5CF6` core violet
- `#5A6AF5` intelligence blue
- `#1F3ABD` deep signal blue
- `#120E2B` navy ink

## Usage

- Navy is used for major text, premium surfaces, and the app icon background.
- Violet and blue gradients are used for brand emphasis, primary actions, selected navigation, and charts.
- Pale violet surfaces are used for selected states and low-emphasis panels.
- Amber remains reserved for caution.
- Red remains reserved for blocked, frozen, critical, or fail-closed states.

## Rule

Raw technical constants are not primary labels. They remain available in tooltips, drawers, audit views, and exports.
