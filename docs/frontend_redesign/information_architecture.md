# Information Architecture

## Shell

The redesigned interface uses:

- Collapsible sidebar
- Page-aware top command bar
- Compact operating status rail
- Page header
- Analytics-first main content
- Right-side detail drawer

## Page Pattern

Every major page follows:

1. Context and controls
2. KPI row
3. Primary visual analysis
4. Comparative panels
5. Alerts or decision queue
6. Evidence table
7. Drawer for technical/audit details

## Progressive Disclosure

Readable labels are shown first. Canonical values such as `PAPER_TRADING_ONLY` and `LIVE_EXECUTION_ENABLED=false` remain available through chip tooltips and the operating controls drawer.
