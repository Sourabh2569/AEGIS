# Design Tokens

Tokens are centralized in `apps/web/app/globals.css`.

## Core Tokens

- `--aegis-950` through `--aegis-50`
- `--brand-gradient`
- `--brand-gradient-dark`
- `--ink-950` through `--ink-400`
- `--canvas`
- `--surface`
- `--surface-muted`
- `--border`
- `--border-subtle`
- `--warning-*`
- `--danger-*`
- `--info-*`

## Semantic Tone Tokens

- `--tone-success`
- `--tone-warning`
- `--tone-danger`
- `--tone-info`
- `--tone-neutral`

## Usage

Components use tone classes such as `tone-success`, `tone-warning`, and `tone-danger` instead of hard-coded one-off colours.
