# Evidence Package Specification

Evidence packages must include origin, provider, rights, raw objects, dataset version, instrument master, universe, corporate actions, calendar, benchmark, feature runs, strategy, hypothesis, frozen manifest, cost/slippage/settlement/risk versions, orders, fills, ledgers, NAV, exposures, risk assessments, drawdown, benchmark, metrics, attribution, stress tests, exceptions, holdout usage, audit references, software commit, completion state, and known limitations.

Every package states: actual historical research only, not validated, not paper-trading eligible, not live-trading eligible, no real capital deployed.
